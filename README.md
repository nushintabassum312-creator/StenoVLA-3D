# StenoVLA-3D project website

This folder is ready for GitHub Pages.

## Publish

1. Create a public GitHub repository such as `StenoVLA-3D`.
2. Upload every file and folder here to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The page will be available at `https://YOUR-USERNAME.github.io/StenoVLA-3D/`.

After arXiv assigns the permanent identifier, replace the disabled “arXiv pending” element in `index.html` with a link and update the BibTeX block.
